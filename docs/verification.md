## Practical limits

At the verified 48 kHz/512-frame configuration, processing delay is 960 samples (20 ms), plus device buffering for live monitoring. A larger prepared host block raises the processing delay when necessary. A 512-frame device buffer is the starting configuration for this laptop; reliable 128-frame operation is not established. Thirty-two simultaneous R3-stretched voices exceed measured live throughput, although they work offline. The overload counter records fail-silent voice reset; zero counted overloads alone do not prove an audio callback met every wall-clock deadline. Neutral playback and Repitch are much cheaper.

The API has fixed PCM/history budgets and 32 voices. It does not implement SLAB hardware, proprietary Serato algorithms or file formats, a guaranteed 192 kHz/variable-block performance envelope, or perfect source separation. Generic host MIDI and text cue exchange provide the supported interoperability.

Private recordings, stems, REAPER projects and raw audio evidence stay in ignored local directories. Public source and synthetic test generators are sufficient to inspect the implementation; some integration tests additionally require the installed host, optional analyzer, worker and authorized local source.

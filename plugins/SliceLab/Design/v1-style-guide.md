# SliceLab visual style

Use graphite backgrounds, slightly lighter panels, thin warm-gray separators, and off-white primary text. Orange identifies the selected slice and key actions. Use cyan, magenta, amber, and violet consistently for the four stems. Keep waveform detail legible over pad colors.

Use a clear sans-serif typeface and a fixed-width face for time and numeric data. Controls align to an eight-pixel spacing rhythm. Corners are modestly rounded. Selected and disabled states must differ in brightness as well as color. Level meters and voice activity are animated from processor telemetry.

Use original vector drawing and JUCE controls. No copied product artwork or logos are included.

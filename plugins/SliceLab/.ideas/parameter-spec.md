# SliceLab parameters

The shared structures in `Source/Domain.h` define the ranges and meanings used by the editor and processor. Host parameters must match their validated ranges.

Global controls include source BPM, target BPM, beat offset, host sync and multiplier, gain, semitones, cents, trigger or hold, mono or poly, keyboard mode, root note, and four stem switches and levels.

Each of 32 pads has original-source start and end times, gain, pan, semitones, cents, time ratio, filter cutoff and resonance, attack and release, reverse, loop, favorite, output, and name.

Slice commands include transients, beat grid, equal, random, find best, manual creation, deletion, duplication, boundary editing, undo, and redo. File commands include load or relink sample, save or load preset, collect media, export processed WAV, and export MIDI.

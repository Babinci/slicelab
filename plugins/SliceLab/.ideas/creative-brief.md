# SliceLab

An open-source Linux instrument for turning records into playable material. Load a song, see its tempo and key, choose or create 32 slices, and play them from MIDI or the pads. Separate the source into vocals, drums, bass, and other on a configured remote GPU. Adjust stems inside the instrument.

The central workflow keeps the full source visible alongside a detailed editable slice. Tempo, pitch, and slice boundaries remain independent. Pad sound controls, output routing, presets, media collection, and host project recall support production work.

The visual design is an original dark graphite studio instrument with pale typography, orange selection, and distinct stem colors. It uses native JUCE input and drawing on Linux.
